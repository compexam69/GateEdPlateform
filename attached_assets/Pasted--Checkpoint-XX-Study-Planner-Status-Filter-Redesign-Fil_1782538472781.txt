🟢 Checkpoint XX: Study Planner Status Filter Redesign (Filter Chips → Dropdown Filter)

Goal:

Redesign the task filtering system in the Study Planner module by replacing the existing horizontal status filter chips (**All, Pending, In Progress, Completed, Skipped**) with a single compact dropdown filter. The dropdown should provide the same filtering functionality while improving usability, reducing screen space usage (especially on mobile devices), and maintaining a clean, modern, and responsive interface.

Context:

Currently:

• The Study Planner displays multiple status filter chips:

* All
* Pending
* In Progress
* Completed
* Skipped

• These chips consume excessive horizontal space, particularly on mobile devices.
• The interface becomes cluttered and less responsive on smaller screens.

New Requirement:

• Remove the existing status filter chips.
• Replace them with a single dropdown filter.
• The default selected option must be **All**.
• Position the dropdown on the right side of the filter section while maintaining proper alignment with the page layout.
• When tapped/clicked, the dropdown must display:

* All
* Pending
* In Progress
* Completed
* Skipped
  • Selecting an option should instantly filter the task list.
  • Preserve all existing filtering logic and Planner functionality.
