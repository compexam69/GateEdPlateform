🟢 Checkpoint X: Responsive Appearance Section (Mobile Collapsible + Desktop Expanded Layout)

Goal:

Optimize the **Appearance** section inside the Profile module using a responsive, device-specific layout strategy.

Requirements:

• On mobile devices, the Appearance section should behave as a collapsible/dropdown component to save screen space and maintain a clean UI.
• On desktop devices, the Appearance section should be permanently expanded and displayed without dropdown functionality.
• The desktop implementation should follow the same behavior currently used for the Change Password section (always visible and expanded).
• The final design must improve usability, responsiveness, visual balance, and efficient use of screen space while preserving all existing theme-selection functionality.

2. Implement Responsive Appearance Behavior
━━━━━━━━━━━━━━━━━━━━━━━

Mobile Behavior (<768px):

• Appearance section remains collapsible
• Users can expand/collapse manually
• Default state may remain collapsed if currently implemented
• Saves vertical screen space
• Preserves clean mobile layout

Desktop Behavior (≥768px):

• Remove dropdown/collapse behavior entirely
• Automatically display Appearance content
• Always show all theme options
• No expand/collapse interaction required
• Use available desktop screen space efficiently

Ensure:

• Mobile and desktop behaviors are completely independent
• No state conflicts occur when resizing between breakpoints
