## **Implementation Prompt: Mobile-First Instagram-Style Authentication Redesign (Login & Register)**

Analyze the existing **Login** and **Register** pages of the project before making any changes. Redesign both authentication pages to follow a clean, modern, **Instagram-inspired authentication UI** while preserving **100% of the existing authentication functionality, validation, API integration, Supabase authentication, routing, session management, error handling, and business logic**.

The implementation must follow a **mobile-first responsive design** approach, while also providing an optimized experience on tablets and desktop screens.

---

# Goal

Completely redesign the authentication UI without changing any backend functionality.

The final result should feel like a modern production-grade authentication experience similar to Instagram while remaining fully compatible with the existing project.

---

# UI Requirements

## 1. Mobile-First Layout

Design the authentication pages primarily for mobile devices.

Requirements:

* Content centered vertically and horizontally
* Maximum readability
* Comfortable thumb reach
* Proper safe-area spacing
* No horizontal scrolling
* Minimal vertical scrolling
* Responsive spacing
* Professional appearance

---

## 2. Center Authentication Card

Place the entire authentication UI inside a centered card.

The card should include:

* Application Logo
* Application Name
* Welcome text
* Login/Register form
* Authentication actions
* Footer links

Desktop:

* Centered card
* Appropriate max-width
* Professional spacing

Mobile:

* Full-width card with margins
* Comfortable padding
* Optimized spacing

---

## 3. Logo Section

Top section should contain:

* App logo
* App name
* Small welcome subtitle

Example:

```
App Logo

StudyFlow

Welcome back.
Continue your learning journey.
```

---

## 4. Login Form

Include:

* Email
* Password

Password field must support:

* Show/Hide password toggle
* Proper validation
* Accessible labels

---

## 5. Register Form

Include:

* Full Name
* Email
* Mobile Number (if supported)
* Password
* Confirm Password

Preserve all existing validation rules.

---

## 6. Buttons

Primary button:

* Full width
* Consistent height
* Rounded corners
* Loading indicator
* Disabled while submitting

Examples:

```
Log In

Sign Up
```

---

## 7. Forgot Password

Display as an inline text link.

Requirements:

* Right aligned
* Below password field
* Small spacing
* Mobile friendly

Example:

```
Forgot password?
```

Do not modify existing reset-password functionality.

---

## 8. Divider

Below the primary button add a subtle divider.

Example:

```
──────── OR ────────
```

Maintain existing social login functionality if implemented.

## 9. Bottom Toggle

Bottom section should contain:

Login page:

```
Don't have an account?

Sign Up
```

Register page:

```
Already have an account?

Log In
```

The toggle should:

* Preserve routing
* Preserve existing navigation
* Preserve browser history behavior
