🟢 Checkpoint XX: Tests Module Filter Bar Redesign, Status Filtering & Responsive Search Enhancement

## Goal

Redesign the top filter bar of the **Tests** module to provide a cleaner, faster, and more intuitive filtering experience while preserving all existing functionality.

The new filter bar should include:

* **Test Type** dropdown on the left (default: current selected test type)
* **Status** dropdown in the center (default: **All**) with filtering options
* **Search** icon on the right that expands into a search field when tapped/clicked

The selected status should instantly filter the test list without requiring additional actions.

The redesign must completely replace the existing status chips while maintaining all existing test functionality, responsiveness, accessibility, and performance.

---

# Context

Currently:

* Test Type filtering already exists.
* Status filtering is implemented using multiple status chips/buttons.
* Search functionality may already exist separately.
* The current layout occupies unnecessary space and is less scalable on mobile devices.

New Requirements:

* Replace status chips with a Status dropdown.
* Preserve Test Type filtering.
* Add an expandable Search control.
* Maintain responsive behavior.
* Preserve all existing filtering functionality.
* Do not introduce regressions.

---
