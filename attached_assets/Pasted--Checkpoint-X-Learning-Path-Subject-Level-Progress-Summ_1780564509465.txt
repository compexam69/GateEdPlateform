# 🟢 Checkpoint X: Learning Path Subject-Level Progress Summary & Dynamic Chapter Completion Tracking

## Goal

Enhance the **Learning Path** module by adding a **Subject-level Progress Summary** below each Subject card that displays:

* The number of **completed chapters out of total chapters** (e.g., **5/12**)
* A **visual progress bar** positioned on the same row to indicate completion percentage

The progress summary must update dynamically based on the user's actual chapter completion status and remain responsive, compact, and visually consistent across mobile and desktop devices without disrupting the existing Subject card design.

---

## Context

Currently:

* Subject cards display subject information.
* Users can track progress at the chapter/topic level.
* There is no quick subject-level overview showing overall chapter completion.

This makes it difficult for users to:

* Quickly assess progress within a subject.
* Compare completion status across multiple subjects.
* Identify which subjects need attention.

The new progress summary should provide an at-a-glance view of subject completion while maintaining the existing Learning Path UI.

---

# Requirements Analysis

The requirement is not merely adding a progress bar.

The implementation must:

### Display Chapter Completion Summary

Show:

* Completed Chapters
* Total Chapters

Example:

* 0/12
* 3/12
* 12/12

### Display Dynamic Progress Bar

Calculate:

Progress % = (Completed Chapters ÷ Total Chapters) × 100

Examples:

* 0/12 = 0%
* 3/12 = 25%
* 6/12 = 50%
* 12/12 = 100%

The visual bar must always reflect actual progress.
