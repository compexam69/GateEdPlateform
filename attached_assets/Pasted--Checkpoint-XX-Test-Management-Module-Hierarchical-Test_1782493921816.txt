🟢 Checkpoint XX: Test Management Module – Hierarchical Test Creation, CSV Import & Role-Based Access Control

## Goal

Implement a new **Test Management Module** within the Admin and Super Admin Dashboard that enables administrators to create tests using the existing academic hierarchy (**Class → Subject → Chapter**) and import questions through CSV files.

The module must integrate seamlessly with the existing Quiz/Test system, Content Editor hierarchy, User Management, Content Access Control, Analytics, and Student application without duplicating data or breaking existing functionality.

Unlike the existing Quiz & Question Editor, this module should focus on **hierarchical test creation**, **bulk question import**, and **role-based access management**, making large-scale test creation significantly faster and easier.

---

## Context

Currently:

* The Quiz & Question Editor allows manual creation and bulk import of questions.
* The Content Editor already manages:

  * Classes
  * Subjects
  * Chapters
  * Topics
* Content Access Control already manages visibility permissions.
* Role-based access already exists for Subjects, Lectures and Exams.

However, there is no dedicated module that allows administrators to:

* Select an existing Class
* Select a Subject belonging to that Class
* Select a Chapter
* Upload a CSV question file
* Automatically create a complete test
* Manage who can view the test
* Manage who can attempt the test

The new module should reuse existing architecture wherever possible.

# 8. Permission Rules

Maintain existing ownership rules.

Super Admin

* Can view all tests.
* Cannot edit another Super Admin's test unless granted permission.
* Can manage own tests.

Admin

* Can manage own tests.
* Can access shared tests.
* Cannot edit tests without permission.

Students

* Can only see tests they have permission to view.
* Can only attempt tests they have permission to attempt.

Respect all existing RLS policies.
