🟢 Checkpoint X: Global Theme System (Dark/Light Mode + Ebony, Carbon & Monokai Themes)

Goal:

Implement a fully production-ready global theme system that adds:

• Dark/Light mode toggle
• Multiple selectable themes:
• Ebony
• Carbon
• Monokai

The theme system must persist user preferences in BOTH:

• localStorage
• Supabase profile data

so that the selected theme remains synchronized across:

• Page refreshes
• Logout/login cycles
• Different devices
• Multiple sessions

The implementation must provide a clean, responsive, visually polished, and consistent UI/UX across the entire application.

4. Supabase Database & SQL Requirements

Analyze whether the profiles table already supports theme storage.

If NOT:

Create required SQL migration.

Recommended column:

• theme_preference TEXT

Allowed values:

• light
• dark
• ebony
• carbon
• monokai

Provide:

A. SQL migration script
B. Rollback SQL
C. RLS policy updates if required

Example requirements:

• Users can update ONLY their own theme preference
• Theme preference must NOT expose other user data

Explicitly explain:

• Where to run SQL
• Whether existing users are affected
• Whether backfill/default values are required

If SQL changes are NOT required:

Explicitly state:

"No SQL Editor changes are required."
