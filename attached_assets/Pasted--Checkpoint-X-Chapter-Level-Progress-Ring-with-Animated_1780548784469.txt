🟢 Checkpoint X: Chapter-Level Progress Ring with Animated Completion Tracking

Goal:

Implement a production-ready **Chapter Progress Ring** on the **ChapterDetailPage** that visually displays the percentage of Topics completed within the current Chapter.

The progress ring must:

• Calculate completion percentage based on completed Topics within the Chapter.
• Display the current completion percentage numerically.
• Animate smoothly using Framer Motion.
• Update automatically when Topic completion status changes.
• Remain responsive across mobile, tablet, desktop, and PWA environments.
• Integrate cleanly with the existing ChapterDetailPage design.

The implementation should improve student progress visibility while maintaining performance, accessibility, and UI consistency throughout the application.

3. Progress Calculation Logic
━━━━━━━━━━━━━━━━━━━━━━━

Calculate progress using:

Completed Topics ÷ Total Topics × 100

Requirements:

• Handle Chapters with many Topics
• Handle Chapters with few Topics
• Handle empty Chapters safely
• Handle partially completed Chapters
• Handle fully completed Chapters

Edge Cases:

No Topics:

• Show 0%
• Do not divide by zero
• Display appropriate fallback state

All Topics Completed:

• Show 100%
• Trigger completion animation if desired
