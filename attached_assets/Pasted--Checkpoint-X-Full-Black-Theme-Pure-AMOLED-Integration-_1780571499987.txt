# 🟢 Checkpoint X: Full Black Theme (Pure AMOLED) Integration for Appearance Settings

## Goal

Add a new **Full Black Theme (Pure AMOLED Theme)** to the existing Appearance/Theming system alongside the existing themes (Light, Ebony, Carbon, Monokai, etc.).

The Full Black Theme must use true black (`#000000`) backgrounds wherever appropriate to maximize contrast, reduce battery consumption on OLED/AMOLED displays, and provide a premium dark-mode experience.

The theme must integrate seamlessly with the existing theme system, support instant switching, persist across sessions and devices, and remain visually consistent throughout the entire application.

---

## Context

Currently:

* The application supports Light/Dark appearance modes.
* Additional themes such as:

  * Ebony
  * Carbon
  * Monokai
    exist in the Appearance section.
* Some users prefer a true-black AMOLED experience rather than dark gray backgrounds.

The new Full Black Theme should provide:

* Pure black backgrounds
* High contrast UI
* Consistent styling
* Improved OLED battery efficiency
* Better nighttime usability

without affecting existing themes.

---

# Requirements Analysis

The requirement is not simply changing background colors.

The implementation must:

### Add New Theme
